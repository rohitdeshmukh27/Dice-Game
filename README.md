# 🎲 Dice Game – React Project

Welcome to my redesigned version of the **Dice Game** project built while following the [React 10 Projects Series by Shubham Sable](https://youtu.be/DY9LK7mq86s?list=PLPppPPmk0i3j_DW1T-UbryDVhBDgaAfEp). This project focuses on core React concepts and offers a simple, interactive game where players roll dice and match values to win.

🔗 **Live Website**: [Dice Game - GitHub Pages](https://rohitdeshmukh27.github.io/Dice-Game/)
